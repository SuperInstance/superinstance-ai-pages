# superinstance-ai-pages

Static site source for [superinstance.ai](https://superinstance.ai), deployed via GitHub Pages.

The site documents the SuperInstance / Cocapn Fleet approach to structuring
applications as room-based environments ("MUDs") coordinated by agents. It
ships the HTML/CSS/JS for the landing page, interactive demos, and the
specification documents held in this repo.

## Repository contents

- `index.html` and the `*.html` demo pages — the public site
- `css/`, `assets/` — styles and images
- `*.md` specs — architecture, protocol, and roadmap documents (e.g.
  `FLEET-ARCHITECTURE.md`, `plato-spec.md`, `ECOSYSTEM-SYNTHESIS.md`)

## Fleet context

projects. Deployment status varies by domain. Domains confirmed live today:

- ✅ [superinstance.ai](https://superinstance.ai) — this site
- ✅ [makerlog.ai](https://makerlog.ai)
- ✅ [cocapn.ai](https://cocapn.ai) — fleet hub

Landing-page work in progress (repos exist, not all deployed):

- ⚠️ [fishinglog.ai](https://fishinglog.ai)
